01 / RESEARCH DETAIL갈망 추정에서 알림과 대화까지 / 시제품의 현재 구현 범위

난제
웨어러블 분류 결과를 상태 확인과 알림으로 연결하고 위험 판정과 LLM 대화의 역할을 구분해야 한다.
해결
백엔드 규칙으로 위험 단계와 알림 시점을 결정했다. 앱에서 상태 확인, 설문, 음성 대화를 지원한다.
기여
기술 리드와 PM을 맡아 위험 판정과 백엔드를 구현하고 앱 알림, 한국어 STT, TTS를 통합했다.
NeuroTruth 시제품의 구현 범위
현재 기능 구현 범위
생체 입력 PPG, EDA 기반 4단계 갈망 추정
대화 지원 AWS Bedrock LLM, STT, Android TTS
기록 AUQ 설문, 상태 및 알림 이력
평가 조건 및 연구 범위중간결과보고서의 시제품 화면. 생체-언어 불일치 분석 MBID와 임상 개입 효과 검증은 후속 개발

02 / RESEARCH DETAIL갈망 분류와 시스템 통합 평가 / 알림 전달 지연 측정

통합 결과
분류, 위험 판정, 알림, 대화의 연결을 확인했다. 동일 시나리오의 반복 통합 시험에서 21회 모두 성공했다.
추가 확인
별도의 카메라 시험에서 정적 영상 10개를 모두 처리했다. 20초 영상의 평균 처리시간은 14.8초였다.
다음 단계
MBID 불일치 점수와 개입 전후 효과를 검증할 예정이다. 2개 병원에서 약 80명을 대상으로 임상평가를 계획하고 있다.
통합 시험과 지연 측정 범위
측정 범위 해석
통합 시험 MBID를 제외한 반복 기능 시험
지연 알림 전달시간, LLM 응답시간 제외
추가 자료 MBID 성능 및 임상평가 결과
평가 조건 및 연구 범위카메라 시험은 유효 처리율과 처리시간을 평가. 심박 정확도 또는 임상 개입 효과의 근거로 사용하지 않음
