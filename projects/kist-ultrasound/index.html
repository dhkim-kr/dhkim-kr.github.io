01 / RESEARCH DETAIL영상 좌표와 추적 좌표의 정합 / 3D Slicer 모듈 구현

난제
CT/MRI, 추적장치, 탐침의 좌표계가 달라 추적 위치를 영상과 측정 위치에 연결해야 한다.
해결
랜드마크 및 표면 정합으로 Reference와 RAS 좌표를 연결했다. 탐침의 위치 변환을 영상 단면에 실시간으로 반영했다.
기여
3D Slicer Python 모듈과 장치 연동을 개발했다. 연구용 모듈을 패키징하고 전임상 연구자와 동작을 검증했다.
좌표 정합 및 추적 기능
구현 항목 동작
좌표 변환 ReferenceToRAS × TipToReference
단면 갱신 Red / Green / Yellow 위치 반영
모듈 구성 정합, 추적, 이동 제어, 파형 취득
평가 조건 및 연구 범위KIST 인턴 당시 발표 자료의 영상 안내와 장치 제어 구현 결과이다. 치료 효과를 평가한 결과는 포함하지 않는다.

02 / RESEARCH DETAIL이동과 취득의 순차 제어 / 대기시간 조정과 음장 시각화

난제
좌표 이동마다 대기시간이 누적된다. 각 측정 위치와 취득 파형의 대응 관계도 유지해야 한다.
해결
이동 간격과 대기시간을 조정하는 VXM 제어를 구현했다. 격자별 파형을 취득하고 평면별 음장 분포를 생성했다.
기여
로봇 이동, 파형 취득, 음장 시각화를 연결했다. 3D Slicer에서 측정 절차와 결과를 확인하도록 구성했다.
이동 대기시간 계산 비교
원본 시간 비교 계산 결과
기존 0.7 × 21 = 14.7초
조정 후 0.7 + 0.3 × 8 + 1.3 = 4.4초
개선 비율 약 3.3배
평가 조건 및 연구 범위KIST PPT의 시간 계산 비교. 추가 자료: 표적 오차의 단위, 기준 위치와 반복 검증표
