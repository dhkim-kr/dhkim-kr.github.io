연구 내용

다중 시간척도 합성곱, 파라미터 없는 시간 어텐션, 분리형 정제로 작은 운동상상 EEG 디코더를 구성했다.

결과

BCI IV 2a 세션 독립 정확도 70.81 ± 0.49%, 파라미터 1.84K, 데스크톱 CPU 지연 1.46 ms(batch size 1).
