01 / RESEARCH DETAILASGCRL: adaptive graphs and contrastive learning

Problem / context
Incorrect connections in fixed similarity graphs can propagate errors when labels are scarce.
Approach
Updated connections with learned representations and used adaptive augmentation to preserve class relationships during contrastive learning.
Contribution / next steps
Designed the method, implemented the model, conducted ablations and wrote the first-author KBS 2026 paper as a follow-up to SGCL.

02 / RESEARCH DETAILSimNeXt-EEG: compact temporal attention

Problem / context
A small motor-imagery model must capture multiple temporal scales and suppress noise.
Approach
Extracted temporal features with multiple kernels and recalibrated time points using parameter-free SimAM attention.
Contribution / next steps
Designed the model, measured classification accuracy and CPU latency, and conducted ablations for the first-author IEEE SPL 2026 paper.
Model specification and evaluation 1
