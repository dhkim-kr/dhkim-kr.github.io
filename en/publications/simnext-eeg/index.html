SimNeXt-EEG: Compact Motor Imagery EEG Decoding via Parameter-Free Temporal Attention and Separable Refinement

Published, Early Access

Venue
IEEE Signal Processing Letters
Author role
First author
Year
2026
DOI GitHub

Research approach

Built a compact motor-imagery EEG decoder using multiscale convolution, parameter-free temporal attention and separable refinement.

Results

BCI IV 2a session-independent accuracy: 70.81 ± 0.49%; 1.84K parameters; 1.46 ms desktop CPU latency at batch size 1.

SimNeXt-EEG architecture
Stage Operation / output
MSTF Temporal kernels 32, 80 / 8 channels
STE Spatial separable convolution + SimAM
STR Temporal separable convolution + SimAM
Classification Flatten, Linear / 4 classes
